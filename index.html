Isto é seguro? Is this safe?

É um projeto pessoal de código aberto — todo o código Kotlin está neste repositório para inspecionares. O APK usa uma assinatura de desenvolvimento (debug), por isso o Android avisa que a origem é desconhecida; isso é esperado para qualquer app instalada fora da Play Store, não um sinal de problema.

This is a personal open-source project — all the Kotlin code is in this repository for you to inspect. The APK uses a debug signature, so Android will warn the source is unknown; that's expected for any app installed outside the Play Store, not a red flag.
